# Estado de aprendizaje

- `LEARNING_STATE.md`: resumen canónico del estado actual de este programa.
- `EVIDENCE_LOG.md`: historial append-only de evidencias observadas.
- `CONCEPT_MAP.md`: mapa relacional recomendado como fuente del Proyecto desde el inicio, pero no obligatorio para el tutor. Registra relaciones justificadas, sin duplicar el currículo ni demostrar dominio por mera presencia.
- `LAST_HANDOFF.md`: artefacto generado después de un cierre real de sesión.

No inventes progreso ni copies evidencia de otro Proyecto. Verifica las actualizaciones antes de reemplazar archivos locales o del Proyecto de ChatGPT.
