# Mapa conceptual — Deep Learning

Mapa opcional para registrar relaciones causales, prerrequisitos, contrastes, límites de analogías y decisiones condicionadas. No es un duplicado del currículo y la presencia de un concepto no demuestra dominio.

## Relaciones iniciales por explorar

- Pregunta o problema → representación → método elegido → resultado observable.
- Supuestos → mecanismo → condiciones de validez → modos de fallo.
- Datos/evidencia → evaluación → incertidumbre → decisión revisable.
- Complejidad adicional → beneficios esperados → coste/riesgo → criterio para conservarla o retirarla.

Añade relaciones concretas solo después de que resulten útiles en el aprendizaje.
