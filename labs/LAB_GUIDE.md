# Laboratorios — Deep Learning

Los laboratorios son optativos y se proponen cuando ayudan a comprobar un mecanismo o una hipótesis. Antes de un ejercicio extenso, explica su objetivo, entregable y criterio de evaluación, y espera aceptación salvo que el estudiante lo haya solicitado.

Un laboratorio puede ser conceptual, matemático, experimental, visual o implementado. No se exige código cuando otra representación permite demostrar la comprensión.

> **Identidad de fuente:** documento de `sets-deep-learning`. Si se carga en un Proyecto de ChatGPT, su nombre visible es `LAB_GUIDE.md`; no se presupone que la interfaz conserve la carpeta.
